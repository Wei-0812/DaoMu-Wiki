# Daomu Wiki (盜墓筆記百科) 專案開發指南

## 1. 專案目的
建立一個關於《盜墓筆記》小說世界觀的靜態百科網站，統整散落的人物、地點、明器（古董）與專有名詞，方便讀者查閱。

## 2. 網頁整體風格
*   **視覺語彙**：懸疑、探險、復古。
*   **色調**：採用深色模式 (Dark Mode) 為主，背景使用深灰或深褐色，文字為淺灰色，強調色（如標題、連結）使用暗紅色或青銅綠色。
*   **排版**：極簡乾淨，適合大量文字閱讀，每個條目需要有清晰的層級標題 (H1, H2, H3)。

## 3. 頁面與資料夾結構
專案目錄結構如下：
- /index.html (網站首頁：提供搜尋框概念與熱門條目列表)
- /css/style.css (共用樣式表)
- /characters/ (存放人物介紹頁面)
- /locations/ (存放地點/墓穴介紹頁面)
- /artifacts/ (存放明器/法寶介紹頁面)

## 4. 檔案命名與放置規則
*   所有的 HTML 檔案命名必須使用「英文全小寫」加上「連字號 (-)」，例如吳邪的頁面必須命名為 `wu-xie.html`，張起靈為 `zhang-qiling.html`。
*   所有的分類頁面必須存放在對應的資料夾中。

## 5. 新增內容時要遵守的格式 (Component Rules)
當要求 AI 新增一個「人物介紹 (Character)」頁面時，必須嚴格包含以下 HTML 結構：
1. `<header>`：包含導覽列，可以連回首頁。
2. `<div class="profile-card">`：
   - 姓名 (Name)
   - 稱號/外號 (Alias)
   - 陣營/所屬勢力 (Affiliation)
   - 招牌武器/特徵 (Signature)
3. `<div class="biography">`：人物生平與重要事蹟介紹。
4. `<footer>`：版權與免責聲明。

## 6. AI 修改或新增內容時需要遵守的規則 (AI Instructions)
*   **絕不幻想**：本專案為特定小說百科，AI 生成內容必須基於原著設定，若指令中未提供足夠資訊，AI 需生成「[待補充]」的佔位文字，不可自行編造劇情。
*   **組件重用**：新增任何頁面時，必須統一引入 `/css/style.css`，並套用已經定義好的 CSS Class（如 `.profile-card`, `.biography`）。
*   **響應式設計**：確保生成的 HTML 結構在手機與桌機上都能正常閱讀。
